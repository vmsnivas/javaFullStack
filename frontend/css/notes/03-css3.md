# CSS3 Features (Flexbox, Positioning, Video Backgrounds)

## Overview
CSS3 introduced powerful layout and visual features that go beyond the classic box model. This note highlights the key CSS3 capabilities demonstrated in this repo’s examples.

## Key CSS3 Features Covered

### 1) Box-Sizing (`box-sizing: border-box`)
- Ensures `width`/`height` include padding and border.
- Great for building predictable layouts.

### 2) Flexbox (`display: flex`)
- Creates flexible, responsive layouts without float hacks.
- Useful properties shown:
  - `justify-content` (horizontal alignment)
  - `align-items` (vertical alignment)
  - `flex-wrap` (wrap child items to new lines)
  - `flex-direction` (row/column layout)

### 3) Fixed/Sticky Positioning (`position: fixed`, `position: sticky`)
- `fixed` pins elements relative to the viewport (e.g., toast messages).
- `sticky` toggles between static and fixed based on scroll position.

### 4) Object Fit (`object-fit: cover`)
- Controls how replaced elements like `<img>` and `<video>` are resized to fit their containers.

### 5) Video Backgrounds
- Uses `<video muted autoplay loop>` for background visuals.
- Combines video with overlay content using absolute positioning and `z-index`.
