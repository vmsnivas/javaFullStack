# CSS3 Features (Flexbox, Positioning, Video Backgrounds)

## Overview
CSS3 introduced a suite of layout and presentation features that make modern web UI easier to build and more responsive. This note expands on the CSS3 techniques used in this repo, explains why they work, and shows how they are applied in the example code.

---

## 1) Box Sizing (`box-sizing: border-box`)

### Why it matters
By default, the CSS box model adds `padding` and `border` on top of the specified `width`/`height`, which makes layout calculations harder. `box-sizing: border-box` changes that behavior so that padding and border are included inside the declared size.

### How it works
```css
* {
  box-sizing: border-box;
}
```

### Result
- Elements stay within their expected size.
- It becomes much easier to build responsive grids and align components.

### Where used
- `code/flex.css`: sets `* { box-sizing: border-box; }` to normalize sizing across the layout.

---

## 2) Flexbox (`display: flex`)

### Why it matters
Flexbox is a one-dimensional layout system (row or column) that excels at aligning items inside a container and distributing available space.

### Core concepts
- **Flex container**: element with `display: flex` or `display: inline-flex`.
- **Flex items**: direct children of the container.
- `justify-content`: alignment along the main axis.
- `align-items`: alignment along the cross axis.
- `flex-wrap`: whether items should wrap onto multiple lines.

### Example
```css
.features {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
}

.feature {
  width: 30%;
}
```

### Where used
- `code/flex.css` defines a flex container (`.features`) and aligns `.feature` cards evenly.

## 3) Positioning (`fixed` + `sticky`)

### `position: fixed`
- Pins an element relative to the viewport.
- Useful for persistent UI elements like notifications or floating buttons.

Example:
```css
.message {
  position: fixed;
  bottom: 30px;
  left: 30px;
}
```

### `position: sticky`
- Acts like `position: relative` until the element crosses a threshold, then behaves like `fixed`.
- Great for headers that remain at the top while scrolling.

Example:
```css
header {
  position: sticky;
  top: 0;
}
```

### Where used
- `code/flex.css` uses `position: sticky` on `header` and `position: fixed` on `.message`.

## 4) Object Fit (`object-fit: cover`)

### Why it matters
When using `<img>` or `<video>` as a background, you often want it to fill the container without distortion while cropping excess.

### Example
```css
.bg video {
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

### Where used
- `code/bgStyle.css` applies `object-fit: cover` to the `<video>` element to keep the background full-screen.

## 5) Video Backgrounds

### Approach
- Use a `<video>` element with `muted autoplay loop` for continuous playback.
- Place the video behind content using `position: absolute` and `z-index`.
- Overlay content can be centered using Flexbox.

### Example (HTML)
```html
<section class="bgVideo">
  <div class="bg">
    <video src="assets/101735-video-720.mp4" muted autoplay loop></video>
  </div>
  <div class="content">
    <h1>Welcome to CSS</h1>
  </div>
</section>
```

### Example (CSS)
```css
.content {
  position: absolute;
  top: 0;
  width: 100%;
  height: 100vh;
  display: flex;
  justify-content: center;
  align-items: center;
  background-color: rgba(0, 0, 0, 0.61);
}
```

### Where used
- `code/c18-bgVideo.html` (HTML structure)
- `code/bgStyle.css` (styling overlay and video handling)
